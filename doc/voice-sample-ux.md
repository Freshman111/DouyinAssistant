# 「记住你的声音」入口与录音脚本（评审稿）

针对两个问题：设置页要不要加录音入口、录入时说哪些词。先出方案，不改代码。

## 0. 结论

1. 设置页加一个常驻入口，名字用**「记住你的声音」**，副标题说明用途和状态。它同时承担「首次录入」「效果不好时重录」「录入失败后补救」三个职责。
2. 录入脚本**不建议收录全部 12 个指令**，用 5 个词的固定脚本即可：跳过、上滑、下滑、点赞、返回。原因见第 1 节——VoxLock 只取最响的 3 秒做声纹，和说哪个词无关。
3. 第一版建议保留：状态显示、重新录入、试听。删除放到二级入口（长按或管理弹窗），避免误触。

## 1. 为什么不用把 12 个指令都录进去

VoxLock 的录入模型做的是**说话人声纹**，不是词模板：

- sherpa-onnx 的文档写明：声样超过 3 秒时，只取**前 30 秒内最响的 3 秒**参与计算。
- 也就是说，10 秒里真正被用到的只有约 3 秒，而且只关心「这是谁的声音」，不关心说的是哪个词。
- 把 12 个词塞进 10 秒，平均每个词不到 0.9 秒，用户会赶、会含糊，反而降低这 3 秒的质量。
- 命令识别本身由 Paraformer 负责，声纹只负责「把用户从视频人声里挑出来」。

所以脚本的原则是：**词少、每个词说清楚、覆盖最常用的几个动作**，而不是覆盖全部词表。

## 2. 推荐脚本

10 秒，5 个词，每个词约 2 秒（说词 + 停顿）：

| 顺序 | 提示词 | 作用 |
| --- | --- | --- |
| 1 | 跳过 | 最高频指令，优先保证 |
| 2 | 上滑 | 下一个视频 |
| 3 | 下滑 | 上一个视频 |
| 4 | 点赞 | 双击类动作 |
| 5 | 返回 | 退出类动作 |

「翻页 / 下一页 / 上一页 / 上一条 / 下一条 / 收藏 / 退出」不单独录：

- 下一页、翻页和上滑是同一个手势；上一页、上一条和下滑是同一个手势；退出和返回是同一个手势。
- 收藏目前 `Command` 枚举里没有，属于缺功能，不是缺声样；要支持得另加指令和手势。

如果以后要扩，把脚本做成常量数组即可，不用改录音逻辑。

## 3. 设置页入口

### 3.1 位置

放在「语音控制」和「悬浮窗控制」之间，单独一节：

```
记住你的声音
用你的声音把口令和视频里的说话声分开，录一次即可。
换手机或觉得不准时，可以重新录。
[ 录入我的声音 ]        （已录入时显示：重新录入）
状态：已录入 2026-11-08        （未录入时：未录入，完整识别不可用）
```

### 3.2 状态与行为

| 状态 | 展示 | 点击后 |
| --- | --- | --- |
| 未录入 | 红色/灰色「未录入，完整识别不可用」 | 进入录入页（说明 → 录音） |
| 已录入 | 「已录入 2026-11-08」+ 试听按钮 | 进入管理弹窗：重新录入 / 试听 / 删除 |
| 录入失败 | 保留旧声样，Toast 说明失败原因 | 停留在录入页，可直接重录 |
| 声样损坏/丢失 | 按未录入处理 | 同上 |

### 3.3 首次使用

点「开启语音」且没有声样时，仍弹现有的说明弹窗 → 去录入。录入完成后自动开启语音，并回到设置页，状态变为已录入。

### 3.4 试听与删除

- 试听：播放刚录的 10 秒，让用户确认没有录成别人或环境噪声。
- 删除：二次确认，删除后完整识别不可用，回退关键词识别。

## 4. 录入页调整

现有页面已经有说明、提示词、进度条、音量条和校验，只需要改脚本和文案：

1. 提示词从 4 个循环改成 5 个固定顺序，每个显示 2 秒，最后 1 秒提示「可以了」。
2. 顶部文案改成：「请用平时说口令的音量，依次说下面 5 个词」，并列出 5 个词让用户先看一眼。
3. 校验保持：有效语音 ≥8 秒、峰值 ≥−45 dBFS、削波 <1%。5 个词各 2 秒，正常情况有效语音约 6–8 秒，阈值需要按实测微调（可能降到 6 秒）。
4. 失败文案要具体：太轻 / 太短 / 太响 / 麦克风被占用，分别给不同提示。
5. 录完显示「试听」。
